# M0 — Runnable Contract Baseline

**Scope:** local development, synthetic data, contract-only. Technical slice dan review closure dibedakan. [ADR-0015](../adr/0015-testable-milestone-slices.md) mencatat perluasan M0 agar FE/BE/DB tersedia sejak awal.

## Yang disiapkan

React/Vite FE untuk payload examples, validation report, schema explorer, scoped history dan phase guide. NestJS/Fastify BE dengan Prisma persistence, local app binding, strict request shape, profile/limits checking dan metadata persistence. PostgreSQL nyata memakai cluster/port/schema terpisah. Shared contract package mengekspor types, JSON Schema, draft execution API, dan active lab OpenAPI.

```text
Browser -> local FE proxy -> authenticated M0 API -> contract validation
                                                  -> PostgreSQL m0.contract_checks
Tidak ada jalur menuju provider atau agent runtime pada M0.
```

## Implemented baseline M0

1. Backend memakai **NestJS + Fastify + Prisma + PostgreSQL**.
2. Backend mengikuti **Clean Architecture** dengan automated dependency/cycle rules.
3. Frontend memakai **React + Vite + TypeScript**.
4. Shared package menyediakan **typed contracts, Zod validation, JSON Schema, dan OpenAPI exports**.
5. Contract validation mencakup canonical capability v1: `chat`, `generate`, `structured_generate`, dan `agent_execute`.
6. M0 menyediakan **local application isolation, idempotency, dan PostgreSQL persistence** untuk validation metadata.
7. M0 melakukan **nol provider call, nol agent execution, dan nol billing/financial settlement**.
8. Planned execution surface `/v1/*` **belum live**; endpoint aktif hanya Contract Lab `/api/m0/*`.
9. **Application Registry production, Keycloak federation, AI Connections/Credential Bindings, Plugin Registry, dan distributed runners belum diimplementasikan**; targetnya berada pada P1–P3.
10. [Capability Catalogue](../contracts/CAPABILITIES.md) menetapkan capability M0 sebagai **`CONTRACT_ONLY`**, bukan implemented runtime capability.

## Post-M0 architecture additions

ADR-0019–ADR-0022 menambah target Application/AI Connection registries, credential isolation, plugin registry, optional workspace/remote tools, dan distributed runner fleet. Requirement ini tidak retroaktif membuat M0 mengimplementasikan fitur produksi; Contract Lab tetap hanya memvalidasi contract metadata dan `provider_calls = 0`.

## Configuration invariant

M0 now uses a single validated environment boundary: root `.env` for local development or equivalent process environment in CI. Nest API, Vite proxy, Prisma, Playwright, database bootstrap/migration, contract export, and dev runner consume the same `config/environment.mjs` loader. Required values have no silent defaults; invalid/missing values fail-fast. `.local/config.json`, `DATABASE_URL` as a second path, PostgreSQL binary auto-detection, and browser/port fallbacks are not part of the active implementation.

See [Configuration](../development/CONFIGURATION.md).

## Single-env-gate verification — 21 September 2026

Setelah local values dimigrasikan ke `.env`, legacy `.local/config.json` dihapus. Dengan file legacy sudah tidak ada, `npm run setup` tetap berhasil memulai/menjangkau PostgreSQL, menjalankan Prisma migrate/seed tanpa kehilangan history; **21 integration tests** dan **4 browser E2E tests** lulus ulang.

Current documentation check setelah konfigurasi ini: **66 Markdown files, 509 local links, 0 missing targets**. Ini membuktikan jalur M0 lokal yang diuji tidak bergantung pada hidden JSON config atau fallback tersebut; bukan bukti configuration production M1 sudah selesai.
