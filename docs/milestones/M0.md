# M0 — Runnable Contract Baseline

**Scope:** local development, synthetic data, contract-only. Technical slice dan review closure dibedakan. [ADR-0015](../adr/0015-testable-milestone-slices.md) mencatat perluasan M0 agar FE/BE/DB tersedia sejak awal.

## Yang disiapkan

React/Vite FE untuk payload examples, validation report, schema explorer, scoped history dan phase guide. Fastify BE dengan local app binding, strict request shape, profile/limits checking dan metadata persistence. PostgreSQL nyata memakai cluster/port/schema terpisah. Shared contract package mengekspor types, JSON Schema, draft execution API, dan active lab OpenAPI.

```text
Browser -> local FE proxy -> authenticated M0 API -> contract validation
                                                  -> PostgreSQL m0.contract_checks
Tidak ada jalur menuju provider atau agent runtime pada M0.
```

## Validation evidence

Verified 21 September 2026 (Asia/Jakarta), pada Windows workstation melalui RDC. Node 24.11.1, npm 11.6.2, PostgreSQL 15.5, TypeScript 5.9.3. Dependencies aktual dikunci dalam package-lock.json.

| Check aktual | Hasil |
| --- | --- |
| npm run typecheck | PASS: contracts, API, frontend termasuk Vite config |
| npm test | PASS: 30 unit/contract tests |
| npm run test:integration | PASS: 16 tests terhadap PostgreSQL nyata |
| npm run contracts:check | PASS: generated schemas/OpenAPI sama dengan source |
| npm run build | PASS: seluruh workspace; FE bundle berhasil |
| npm run docs:check | PASS: 54 Markdown, 391 tautan pada pemeriksaan final |
| npm run test:e2e | PASS: 4 browser tests di Microsoft Edge |
| Visual inspection | Desktop 1440px dan mobile 390px diperiksa; tidak ada horizontal page overflow pada fixture mobile |
| npm run db:inspect | PASS: migration 0001, demo profiles, persisted validation metadata tersedia |
| Cluster stop/start + migration replay | PASS: 8 demo record IDs/digests tetap sama setelah PostgreSQL proyek dihentikan lalu dimulai kembali |
| npm install audit | 0 known vulnerabilities pada output install saat pengujian; bukan sertifikasi keamanan |

Coverage: shape/profile constraints, identity override rejection, bounded schema/payload, no coercion, state/accounting separation fixtures, scoped reads, same-key replay/conflict, 20 concurrent duplicates, malformed input, payload cap, pagination, repeatable migration, persistence across API instances, browser reload/navigation dan no live execution route. E2E meninggalkan record demo; test integration membersihkan hanya key miliknya.

Perbaikan yang diverifikasi ulang: Vite config parser, counter assertion berbasis angka bukan whitespace layout, timestamp cursor presisi PostgreSQL, UUID validation dan bounded request traversal. Artifact screenshot/trace lokal berada di test-results (Git-ignored); tidak menjadi input runtime.

Runtime/provider production gates G01–G25 tetap NOT RUN; tes lokal M0 tidak mewakili gate tersebut. Tidak ada chaos/fencing/budget/provider smoke/production security test yang diklaim lulus.

## Tidak termasuk

Tidak ada live chat response, Claude/Codex/Gemini execution, billing, token measurement, Redis lease/SSE replay, tool mutation, artifact upload, real identity federation, production deployment atau migration aplikasi. Validasi metadata yang tersimpan bukan execution job dan bukan financial ledger.
