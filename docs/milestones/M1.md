# M1 — Durable Control Plane Foundation

**Status:** IN PROGRESS. Slice pertama tersedia lokal; P1 belum selesai dan belum production-ready.

## Slice 1 — registry foundation

Implemented FE + BE + PostgreSQL foundation untuk:

- durable `control.applications` registry dengan future Keycloak client mapping;
- durable `control.ai_connections` registry;
- durable `control.credential_instances` metadata dengan central/runner-local residency;
- durable `control.credential_bindings` untuk application/profile → AI connection;
- dedicated/shared connection mode dan `quota_group_ref`;
- read-only `/api/m1/control-plane` snapshot yang tidak mengembalikan secret material;
- Control Plane tab di local UI;
- data-preserving Prisma migration `0002_control_plane_registry`.

Seed lokal hanya membuat Application Registry entries dari M0 fixture identities. **Tidak ada AI Connection, credential instance, atau binding palsu yang dibuat otomatis.**

## Yang belum M1

Keycloak JWT/JWKS verification, operator/admin authorization, management mutations, secret manager/Vault, profile registry production, execution admission/state, budget reservation/ledger, outbox/inbox, audit query, artifact metadata, Redis runner registry/hot state, dan G01/G02/G07/G08/G09/G15/G26–G29 evidence belum selesai.

Current endpoint masih melewati local M0 auth adapter untuk development. Ini sengaja **tidak diklaim sebagai Keycloak implementation atau final management authority**. Sebelum mutation API dibuka, operator authority harus dipisahkan dari application caller sesuai [CONTROL-PLANE](../contracts/CONTROL-PLANE.md).

## Data safety

Actual provider secret tidak ada pada slice ini. `secret_ref` hanya metadata future dan tidak diekspos oleh snapshot API. Existing M0 validation history dipertahankan ketika migration diterapkan.
